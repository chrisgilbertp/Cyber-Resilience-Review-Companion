# Online Resource 1
## Evidence and Governance for Artificial Superintelligence
**Journal:** AI & SOCIETY

This archive reproduces the analytical examples in Sections 5 and 6 and includes the source for the schematic oversight diagram in Section 8.

### Contents
- `reproduce.py` regenerates the three CSV files and both figures.
- `results/compute_growth.csv` tabulates Eq. (4) by month from 0 to 144.
- `results/feedback_sensitivity.csv` gives divergence times for Eq. (2) at the three indicated exponents with I(0) = c = 1.
- `results/physical_bounds.csv` gives the SI inputs and outputs for Eqs. (5) and (6). The two rate quantities have different units.
- Figures are generated by the script (PNG and EPS).

### Reproduce
Run with Python 3. Tested with Python 3.12, NumPy 2.3.5 and Matplotlib 3.10.8. Install NumPy and Matplotlib if needed. Liberation Sans is used for figure labels.

```bash
python -m pip install numpy matplotlib
python reproduce.py --output reproduced
```

The script checks the equations at selected inputs before generating files. It uses the exact SI values for the constants in the report cited in the manuscript (Mohr et al. 2025, DOI 10.1063/5.0279860). The outputs are analytical scenarios and are supplied without empirical or participant-level data. The diagram describes a proposed procedure. The Python plotting code was prepared with ChatGPT assistance as described in the manuscript.
